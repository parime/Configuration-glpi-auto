## 🐛 Reporting Issues

### Before Reporting

1. **Check the FAQ**: [FAQ](docs/faq.md)
2. **Search existing issues**: [GitHub Issues](https://github.com/parime/Configuration-glpi-auto/issues)
3. **Try the latest version**: The issue might already be fixed
4. **Check the documentation**: [Documentation](docs/)

### How to Report

1. **Create a new issue**: [New Issue](https://github.com/parime/Configuration-glpi-auto/issues/new/choose)
2. **Use the appropriate template**:
   - Bug Report template for bugs
   - Feature Request template for new features
3. **Provide all required information** (see below)

### Required Information for Bug Reports

```markdown
## Description
Clear description of the issue

## Steps to Reproduce
1. Go to...
2. Click on...
3. Select...
4. See error

## Expected Behavior
What should happen

## Actual Behavior
What actually happens

## Environment
- Plugin Version: [e.g., 1.0.0]
- GLPI Version: [e.g., 11.0.2]
- PHP Version: [e.g., 8.2.12]
- Database: [e.g., MySQL 8.0]
- Operating System: [e.g., Ubuntu 22.04]

## Additional Context
- Screenshots
- Log files
- Configuration settings
- Browser (for UI issues)

## Possible Solution
If you have suggestions for a fix
```

### Screenshots

If applicable, add screenshots to help explain the problem.

### Log Files

For technical issues, include relevant log entries from:
- `var/log/php_error.log`
- GLPI logs (`glpi/logs/`)
- Plugin-specific logs (if available)

## 🎯 Escalation Process

If your issue is not resolved in a timely manner:

1. **Verify the issue still exists** with the latest version
2. **Provide additional information** if requested
3. **Politely follow up** on the issue/discussion
4. **Escalate to email** support if no response after SLA period
5. **For commercial customers**: Contact your account manager

## 💡 Tips for Getting Faster Support

1. **Be specific**: Provide exact steps to reproduce the issue
2. **Include error messages**: Copy-paste the exact error
3. **Share screenshots**: A picture is worth a thousand words
4. **Describe your environment**: Version numbers are crucial
5. **Be patient**: Community support is volunteer-based
6. **Be polite**: Remember that everyone is trying to help
7. **Follow up**: If asked for more information, provide it promptly
