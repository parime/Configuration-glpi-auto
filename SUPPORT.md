# Support

Configuration GLPI Auto est un projet open source à mainteneur unique : il n'y a pas d'offre
commerciale, de SLA ni d'équipe de support dédiée. Voici où obtenir de l'aide.

## Signaler un bug ou demander une fonctionnalité

[Ouvrez une issue](https://github.com/parime/Configuration-glpi-auto/issues) sur GitHub. Avant de
créer une issue :

1. Vérifiez qu'elle n'existe pas déjà.
2. Vérifiez que vous êtes sur la dernière version (`CHANGELOG.md`).
3. Incluez la version du plugin, la version de GLPI/PHP, et les étapes pour reproduire.

## Questions générales

Utilisez les [GitHub Discussions](https://github.com/parime/Configuration-glpi-auto/discussions)
du dépôt, ou le [forum officiel GLPI](https://forum.glpi-project.org/).

Les PR sont bienvenues : voir [`CONTRIBUTING.md`](CONTRIBUTING.md) pour le cycle de développement
et la suite de vérifications à faire passer avant de proposer un changement.
